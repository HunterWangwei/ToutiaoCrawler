# 今日头条内容采集工具

当前版本：`1.7.2`
更新日期：`2026-08-11`

用于批量采集今日头条微头条的正文、图片和高赞评论。软件提供 Windows 图形界面，可从 TXT 文件批量导入链接，并逐条显示采集进度。

软件包含两个相互独立的功能页：

- `微头条链接采集`：从 TXT 批量导入单篇微头条链接。
- `个人主页采集`：支持输入单个主页，或从 TXT 批量导入多个主页，自动发现并采集微头条。

## 一、直接使用 EXE

运行文件：

```text
dist\ToutiaoCrawler.exe
```

EXE 已包含 Python、拖拽组件和 SOCKS5 支持，其他电脑不需要安装 Python。首次启动时需要释放运行文件，可能会比后续启动慢几秒。

推荐运行环境为 Windows 10/11 64 位。请把 EXE 放在普通、可写的文件夹中运行，不要直接在压缩包、系统目录或只读目录中启动。

软件底部和窗口标题会显示当前版本号。启动后会自动检查 GitHub Releases；发现新版时可直接下载、校验、启动新版本并关闭旧版本。也可点击“检查更新”手动检查。

更新下载期间会显示百分比、已下载大小和文件总大小。新版首先保存为当前软件目录下的 `ToutiaoCrawler-版本号.exe.part`，SHA256 校验通过后改名为 `ToutiaoCrawler-版本号.exe`。软件随后直接启动新文件并关闭旧版本，不再覆盖或删除原 EXE。

自动更新需要当前 EXE 所在目录具有写入权限。旧版会保留作为回退文件，确认新版运行正常后可手动删除不再需要的旧版 EXE。

版本比较支持预发布后缀。同一数字版本下，`alpha < beta < test < rc < 正式版`，因此 `1.7.1-test` 可以识别并更新到正式版 `1.7.1`。

## 二、导入链接

新建一个 TXT 文件，每行放一个今日头条链接，例如：

```text
https://www.toutiao.com/article/1872961296302087
https://www.toutiao.com/article/1872974616713225
```

支持两种导入方式：

1. 把 TXT 文件直接拖入软件的“链接导入”区域。
2. 点击“导入 TXT”按钮选择文件。

软件会自动提取 TXT 中的有效头条链接并去除重复项。

- 支持 UTF-8、UTF-8 BOM 和常见中文 ANSI/GB18030 编码的 TXT。
- “微头条链接采集”支持一次选择多个 TXT，也支持拖入多个 TXT。
- “个人主页采集”目前通过“导入主页 TXT”按钮选择一个 TXT，不支持直接拖入。

## 三、采集设置

### 功能分类

#### 微头条链接采集

保留原有的 TXT 拖入、逐链接采集、S5 代理、违禁词和多线程功能。

#### 个人主页采集

个人主页页签提供独立设置：

- 支持手动输入一个个人主页链接。
- 支持从 TXT 批量导入主页，每行填写一个主页地址。
- 导入时自动提取有效地址、保持原顺序并去除重复项。
- 独立保存目录。
- 独立 SOCKS5 代理。
- 可选 Cookie 文件，用于主页接口需要登录状态的情况。
- 主页页数限制，`0` 表示抓到末页。
- 高赞评论数量 `5–10`。
- 采集模式可选择“内容 + 图片 + 评论”或“仅内容 + 图片”。
- 最低作品评论数，低于该值直接跳过；设为 `0` 表示不限制。
- 发布时间范围支持“不限时间”“仅今天”和“自定义时间段”。
- 自定义日期格式为 `YYYY-MM-DD`，开始日和结束日均包含在采集范围内。
- 首次运行时，开始日期默认使用本机昨天，结束日期默认使用本机当天；之后保留上次保存的设置。
- 并发线程 `1–5`，默认 `3`。
- 独立违禁词列表。
- 每篇主页作品独立显示采集状态。
- 输出 `posts.json` 作为主页作品汇总。
- 自动识别并显示“当前采集作者”。
- 采集结果按主页作者建立独立子目录。
- 多个主页依次处理，每个主页内部继续按照设置的线程数并发采集作品。
- 某个主页读取失败时会记录状态并继续处理下一个主页，不会中断整批任务。

“最低作品评论数”依据头条作品详情返回的评论总数判断，不是依据最终清洗后保存的高赞评论条数判断。时间筛选使用运行软件电脑的本地日期和时区，“仅今天”表示本机当天 `00:00:00–23:59:59`。

选择“仅内容 + 图片”后，软件不会请求评论列表接口，TXT 也不会生成“评论：”标题或空评论区。最低评论数筛选仍然有效，因为筛选使用的是作品详情中的评论总数。

两个页签分别维护输入、状态表、停止控制、保存目录和日志，不会互相覆盖运行状态。

### 保存目录

采集结果会保存在选择的目录中。建议每次任务使用单独目录，便于管理。

### 高赞评论

可选择保留 `5–10` 条评论。软件会抓取多页评论后统一筛选，并不是简单保留最先出现的评论。

如果作品实际评论不足、接口只返回部分评论，或评论在表情与 `@豆包` 清洗后数量不足，最终保存条数可能少于设置值。

评论排序规则：

1. 点赞数高的优先。
2. 点赞数相同时，清洗后字数多的优先。
3. 点赞数和字数都相同时，回复数多的优先。

### 并发线程

可设置 `1–5` 个并发线程，默认值为 `3`：

- `1`：顺序采集，速度较慢但最稳。
- `2–3`：推荐设置，速度和稳定性较均衡。
- `4–5`：适合网络及代理质量较好的环境，但更容易触发网站限流。

同一出口 IP 下不建议超过 5 线程。每篇内容还会请求评论和图片，因此实际网络请求数会高于线程数。

个人主页中的“主页页数”设为 `0` 会持续翻页到接口末页。主页作品很多时任务可能较长，也更容易触发限流；首次测试建议先设置较小页数。

### 违禁词过滤

界面提供“违禁词”输入框，默认内容为：

```text
政治|中央|证券|央行
```

- 多个词使用半角 `|` 或全角 `｜` 分隔。
- 微头条链接采集会检查标题和正文；个人主页采集会检查正文。
- 命中任意违禁词时，状态显示具体命中内容，例如“含违禁词：政治”。
- 命中后不会继续抓取评论或下载图片，也不会生成该文章的 TXT。
- 命中的具体词会写入 `采集日志.txt`。
- 输入框留空可关闭违禁词过滤。
- 修改违禁词后会自动保存，无需点击额外按钮。
- 下次打开软件时会自动恢复上一次填写的内容。
- 配置优先保存在 EXE 同目录的 `config.json`；如果目录不可写，则保存到 `%APPDATA%\ToutiaoCrawler\config.json`。

配置文件示例：

```json
{
  "config_version": 1,
  "blocked_words": "政治|中央|证券|央行|新增词",
  "profile_url": "https://www.toutiao.com/c/user/token/示例Token/",
  "profile_output": "D:\\profile_output",
  "profile_pages": 0,
  "profile_comments": 10,
  "profile_content_mode": "内容 + 图片 + 评论",
  "profile_min_comments": 10,
  "profile_time_mode": "自定义时间段",
  "profile_start_date": "2026-08-10",
  "profile_end_date": "2026-08-11",
  "profile_threads": 3,
  "profile_blocked_words": "政治|中央|证券|央行"
}
```

- 个人主页链接、保存目录、页数、评论数量、最低评论数、日期范围、线程数和违禁词会自动保存。
- S5 代理和 Cookie 文件路径不会写入配置文件，重新启动后需要再次填写或选择，避免敏感信息长期留存。
- 从 TXT 导入的多主页列表只在当前运行期间保留；重新打开软件后需要重新导入。

### SOCKS5 代理

代理输入框留空时使用本机网络。支持以下格式：

```text
127.0.0.1:1080
host:port
host:port:user:password
socks5://user:password@host:port
socks5h://user:password@host:port
```

建议使用 `socks5h`，使域名解析也通过代理完成。

## 四、输出结构

### 微头条链接采集

```text
选择的保存目录\
├─ 内容\
│  ├─ 作品ID_内容开头.txt
│  └─ ...
├─ 图片\
│  ├─ 作品ID_内容开头\
│  │  ├─ 01.jpeg
│  │  └─ 02.jpeg
│  └─ ...
└─ 采集日志.txt
```

- TXT 中只保存正文和评论，不保存标题、摘要、作者、发布时间、原文链接和文章点赞数。
- 评论直接追加在正文后面。
- 个人主页正文结尾的 `【lm】`、`【gmj】` 等已知来源标识会自动清除。
- 评论点赞数仅用于排序，TXT 中不会写入“（赞 N）”。
- TXT 文件名去掉 `.txt` 后，与对应图片文件夹名完全相同。
- TXT 使用 `UTF-8 BOM` 编码，可直接用 Windows 记事本打开。

### 个人主页采集

主页 TXT 示例：

```text
https://www.toutiao.com/c/user/token/主页Token1/?tab=wtt
https://www.toutiao.com/c/user/token/主页Token2/?tab=wtt
```

点击个人主页页签中的“导入主页 TXT”即可载入。仍可在主页链接输入框中手动填写一个主页。

```text
个人主页保存目录\
├─ 主页作者A\
│  ├─ 内容\
│  ├─ 图片\
│  ├─ posts.json
│  └─ 个人主页采集日志.txt
└─ 主页作者B\
   ├─ 内容\
   │  ├─ 作品ID_内容开头.txt
   │  └─ ...
   ├─ 图片\
   │  ├─ 作品ID_内容开头\
   │  │  ├─ 01.jpeg
   │  │  └─ ...
   │  └─ ...
   ├─ posts.json
   └─ 个人主页采集日志.txt
```

- `posts.json` 汇总本次成功采集的主页作品。
- “TXT 中不保存作者、时间和链接”等限制仅针对最终内容 TXT；`posts.json` 是程序汇总数据，会包含作品 ID、作者、发布时间、来源链接、图片列表和评论等结构化字段。
- 同一作者再次采集时会继续使用相同作者目录；本次 `posts.json` 会覆盖该作者目录中上一次的汇总文件，已经生成的内容 TXT 和图片不会统一清空。
- 个人主页和微头条链接采集可以选择不同保存目录。
- Cookie 文件中只应放完整 Cookie 字符串，请勿分享或上传该文件。

## 五、评论清洗规则

为了方便后续程序处理，保存评论前会进行清洗：

- 删除 `[飞吻]`、`[捂脸]`、`[鼓掌]`、`[招财进宝]` 等方括号表情标记。
- 删除 👏、👍、😂、❤️ 等 Unicode 表情和特殊图形符号。
- 表情前后的正常文字会保留。
- 清洗后只剩表情、空白或标点的评论会被丢弃。
- 包含 `@豆包` 的自动问答类评论整条排除。

示例：

```text
祝你们幸福快乐，[招财进宝][招财进宝]
```

保存为：

```text
祝你们幸福快乐，
```

## 六、状态说明

- `等待采集`：尚未开始。
- `采集正文（N秒）`：正在请求和解析正文。
- `采集评论（N秒）`：正在抓取并筛选评论。
- `下载图片（N秒）`：正在保存图片。
- `完成`：该链接已成功保存。
- `含违禁词`：标题或正文命中违禁词，已跳过评论和图片采集。
- 状态会附带命中的具体词，例如 `含违禁词：政治、中央`。
- `评论数不足：3＜10`：作品总评论数低于设置值，不抓评论和图片。
- `超出时间范围：日期时间`：作品发布时间不在设置范围内。
- `发布时间未知`：启用时间限制后无法取得发布时间，为避免误采而跳过。
- `失败：原因`：该链接采集失败，软件会继续处理下一条。
- `已停止`：点击停止后未继续处理的链接。

## 七、网络与故障排查

### 一直停留在“采集正文”

新版具有连接超时、读取超时、硬超时和自动重试，不会无限等待。常见原因包括：

- 对方网络无法访问今日头条。
- DNS 解析异常。
- IP 被临时限制或触发网站风控。
- SOCKS5 代理不可用、账号密码错误或延迟过高。
- 安全软件拦截 EXE 联网。

失败后查看保存目录中的 `采集日志.txt`。日志会记录失败链接、时间和错误原因。

### EXE 无法启动

- 首次启动等待几秒。
- 将 EXE 放到普通可写目录后再运行。
- 检查 Windows Defender 或其他安全软件是否拦截。
- 不要直接在压缩包内运行，先完整解压。

### 检查或下载更新失败

- 自动更新源为 GitHub Releases，电脑必须能够解析并访问 `api.github.com` 和 `github.com`。
- 出现 `NameResolutionError`、`getaddrinfo failed` 或“无法解析 github.com”时，属于 DNS 或网络访问问题，并非更新包损坏。
- 更新器使用“微头条链接采集”页中的 S5 代理；需要通过代理更新时，请先在该页填写可用代理，再点击“检查更新”。
- 如果用户填写的代理或本机直连 GitHub 失败，正式 Release 会自动尝试构建时注入的备用更新代理，并在状态栏显示切换提示。
- 备用代理仅用于检查和下载软件更新，不用于采集今日头条内容。
- 备用代理凭据不会写入公开源码或文档，而是在 GitHub Actions 编译正式 EXE 时通过仓库 Secret 注入。
- 备用代理属于兜底通道，若代理本身到期、拥堵或不可用，仍需手动下载新版或填写其他可用代理。
- 推荐使用 `socks5h`，让 GitHub 域名解析也通过代理完成。
- 无法访问 GitHub 的电脑可由其他电脑下载 Release 中的 EXE，再通过网盘、局域网或 U 盘传输。可以直接使用不同文件名运行，不必覆盖旧版。

### 更新后提示 python312.dll 加载失败

- `python312.dll` 是 PyInstaller 单文件 EXE 内置的 Python 运行库，启动时会释放到 `%TEMP%\_MEI...`，并不是软件额外安装了 Python。
- `v1.7.1` 已取消覆盖原 EXE和 PowerShell替换脚本，改为在当前目录并排保存并启动 `ToutiaoCrawler-版本号.exe`。
- 若仍出现该提示，请彻底退出软件，等待安全软件扫描结束后再次启动。
- 检查 Windows Defender 或其他安全软件的隔离区，确认没有拦截 EXE 释放到 `%TEMP%\_MEI...` 的运行文件。
- 仍无法启动时，删除旧 EXE，重新下载完整 Release 文件，并核对同一 Release 中的 SHA256 校验值。

## 八、源码运行

仅开发或调试时需要：

```powershell
python -m pip install -r requirements.txt
python .\toutiao_ui.py
```

命令行采集：

```powershell
python .\toutiao_crawler.py -n 10 --comment-pages 3 -o output
```

使用代理：

```powershell
python .\toutiao_crawler.py --proxy 127.0.0.1:1080
```

个人主页命令行采集仍是单主页模式，批量主页 TXT 导入属于图形界面功能：

```powershell
python .\toutiao_profile_crawler\crawler.py "https://www.toutiao.com/c/user/token/主页Token/" -o profile_output
```

## 九、使用提醒

- 请控制采集频率，避免短时间发起大量请求。
- 网站接口或页面结构变化后，软件可能需要同步更新。
- 请仅在符合网站规则及适用法律法规的范围内使用。

## 十、发布新版本

项目更新源：`HunterWangwei/ToutiaoCrawler` 的 GitHub Releases。

发布时同步修改 `version.py` 中的版本号，然后创建版本标签：

```powershell
git tag v1.7.2
git push origin v1.7.2
```

GitHub Actions 会注入备用更新代理、构建 `ToutiaoCrawler.exe`、生成 SHA256 校验文件，并使用 `RELEASE_NOTES.md` 发布完整 Release说明。发布前必须配置仓库 Secret `BUILTIN_UPDATE_PROXY`。
