# 今日头条内容采集工具

当前版本：`1.2.0`  
更新日期：`2026-08-09`

用于批量采集今日头条微头条的正文、图片和高赞评论。软件提供 Windows 图形界面，可从 TXT 文件批量导入链接，并逐条显示采集进度。

## 一、直接使用 EXE

运行文件：

```text
dist\ToutiaoCrawler.exe
```

EXE 已包含 Python、拖拽组件和 SOCKS5 支持，其他电脑不需要安装 Python。首次启动时需要释放运行文件，可能会比后续启动慢几秒。

软件底部和窗口标题会显示当前版本号。启动后会自动检查 GitHub Releases；发现新版时可直接下载、校验、替换当前 EXE 并自动重启。也可点击“检查更新”手动检查。

## 二、导入链接

新建一个 TXT 文件，每行放一个今日头条链接，例如：

```text
https://www.toutiao.com/article/1872961296302087
https://www.toutiao.com/article/1872974616713225
```

支持两种导入方式：

1. 把 TXT 文件直接拖入软件的“链接导入”区域。
2. 点击“导入 TXT”按钮选择文件。

软件会自动提取 TXT 中的有效头条链接并去除重复项。

## 三、采集设置

### 保存目录

采集结果会保存在选择的目录中。建议每次任务使用单独目录，便于管理。

### 高赞评论

可选择保留 `5–10` 条评论。软件会抓取多页评论后统一筛选，并不是简单保留最先出现的评论。

评论排序规则：

1. 点赞数高的优先。
2. 点赞数相同时，清洗后字数多的优先。
3. 点赞数和字数都相同时，回复数多的优先。

### 并发线程

可设置 `1–5` 个并发线程，默认值为 `3`：

- `1`：顺序采集，速度较慢但最稳。
- `2–3`：推荐设置，速度和稳定性较均衡。
- `4–5`：适合网络及代理质量较好的环境，但更容易触发网站限流。

同一出口 IP 下不建议超过 5 线程。每篇内容还会请求评论和图片，因此实际网络请求数会高于线程数。

### SOCKS5 代理

代理输入框留空时使用本机网络。支持以下格式：

```text
127.0.0.1:1080
host:port
host:port:user:password
socks5://user:password@host:port
socks5h://user:password@host:port
```

建议使用 `socks5h`，使域名解析也通过代理完成。

## 四、输出结构

```text
选择的保存目录\
├─ 内容\
│  ├─ 作品ID_内容开头.txt
│  └─ ...
├─ 图片\
│  ├─ 作品ID_内容开头\
│  │  ├─ 01.jpeg
│  │  └─ 02.jpeg
│  └─ ...
└─ 采集日志.txt
```

- TXT 中只保存正文和评论，不保存标题、摘要、作者、发布时间、原文链接和文章点赞数。
- 评论直接追加在正文后面。
- TXT 文件名去掉 `.txt` 后，与对应图片文件夹名完全相同。
- TXT 使用 `UTF-8 BOM` 编码，可直接用 Windows 记事本打开。

## 五、评论清洗规则

为了方便后续程序处理，保存评论前会进行清洗：

- 删除 `[飞吻]`、`[捂脸]`、`[鼓掌]`、`[招财进宝]` 等方括号表情标记。
- 删除 👏、👍、😂、❤️ 等 Unicode 表情和特殊图形符号。
- 表情前后的正常文字会保留。
- 清洗后只剩表情、空白或标点的评论会被丢弃。
- 包含 `@豆包` 的自动问答类评论整条排除。

示例：

```text
祝你们幸福快乐，[招财进宝][招财进宝]
```

保存为：

```text
祝你们幸福快乐，
```

## 六、状态说明

- `等待采集`：尚未开始。
- `采集正文（N秒）`：正在请求和解析正文。
- `采集评论（N秒）`：正在抓取并筛选评论。
- `下载图片（N秒）`：正在保存图片。
- `完成`：该链接已成功保存。
- `失败：原因`：该链接采集失败，软件会继续处理下一条。
- `已停止`：点击停止后未继续处理的链接。

## 七、网络与故障排查

### 一直停留在“采集正文”

新版具有连接超时、读取超时、硬超时和自动重试，不会无限等待。常见原因包括：

- 对方网络无法访问今日头条。
- DNS 解析异常。
- IP 被临时限制或触发网站风控。
- SOCKS5 代理不可用、账号密码错误或延迟过高。
- 安全软件拦截 EXE 联网。

失败后查看保存目录中的 `采集日志.txt`。日志会记录失败链接、时间和错误原因。

### EXE 无法启动

- 首次启动等待几秒。
- 将 EXE 放到普通可写目录后再运行。
- 检查 Windows Defender 或其他安全软件是否拦截。
- 不要直接在压缩包内运行，先完整解压。

## 八、源码运行

仅开发或调试时需要：

```powershell
python -m pip install -r requirements.txt
python .\toutiao_ui.py
```

命令行采集：

```powershell
python .\toutiao_crawler.py -n 10 --comment-pages 3 -o output
```

使用代理：

```powershell
python .\toutiao_crawler.py --proxy 127.0.0.1:1080
```

## 九、使用提醒

- 请控制采集频率，避免短时间发起大量请求。
- 网站接口或页面结构变化后，软件可能需要同步更新。
- 请仅在符合网站规则及适用法律法规的范围内使用。

## 十、发布新版本

项目更新源：`HunterWangwei/ToutiaoCrawler` 的 GitHub Releases。

发布时同步修改 `version.py` 中的版本号，然后创建版本标签：

```powershell
git tag v1.2.0
git push origin v1.2.0
```

GitHub Actions 会自动构建 `ToutiaoCrawler.exe`、生成 SHA256 校验文件并发布到 Releases。
