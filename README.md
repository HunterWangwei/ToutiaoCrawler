# 今日头条内容采集工具

当前版本：`1.6.0`
更新日期：`2026-08-11`

用于批量采集今日头条微头条的正文、图片和高赞评论。软件提供 Windows 图形界面，可从 TXT 文件批量导入链接，并逐条显示采集进度。

软件包含两个相互独立的功能页：

- `微头条链接采集`：从 TXT 批量导入单篇微头条链接。
- `个人主页采集`：支持输入单个主页，或从 TXT 批量导入多个主页，自动发现并采集微头条。

## 一、直接使用 EXE

运行文件：

```text
dist\ToutiaoCrawler.exe
```

EXE 已包含 Python、拖拽组件和 SOCKS5 支持，其他电脑不需要安装 Python。首次启动时需要释放运行文件，可能会比后续启动慢几秒。

软件底部和窗口标题会显示当前版本号。启动后会自动检查 GitHub Releases；发现新版时可直接下载、校验、替换当前 EXE 并自动重启。也可点击“检查更新”手动检查。

## 二、导入链接

新建一个 TXT 文件，每行放一个今日头条链接，例如：

```text
https://www.toutiao.com/article/1872961296302087
https://www.toutiao.com/article/1872974616713225
```

支持两种导入方式：

1. 把 TXT 文件直接拖入软件的“链接导入”区域。
2. 点击“导入 TXT”按钮选择文件。

软件会自动提取 TXT 中的有效头条链接并去除重复项。

## 三、采集设置

### 功能分类

#### 微头条链接采集

保留原有的 TXT 拖入、逐链接采集、S5 代理、违禁词和多线程功能。

#### 个人主页采集

个人主页页签提供独立设置：

- 支持手动输入一个个人主页链接。
- 支持从 TXT 批量导入主页，每行填写一个主页地址。
- 导入时自动提取有效地址、保持原顺序并去除重复项。
- 独立保存目录。
- 独立 SOCKS5 代理。
- 可选 Cookie 文件，用于主页接口需要登录状态的情况。
- 主页页数限制，`0` 表示抓到末页。
- 高赞评论数量 `5–10`。
- 最低作品评论数，低于该值直接跳过；设为 `0` 表示不限制。
- 发布时间范围支持“不限时间”“仅今天”和“自定义时间段”。
- 自定义日期格式为 `YYYY-MM-DD`，开始日和结束日均包含在采集范围内。
- 首次运行时，开始日期默认使用本机昨天，结束日期默认使用本机当天；之后保留上次保存的设置。
- 并发线程 `1–5`，默认 `3`。
- 独立违禁词列表。
- 每篇主页作品独立显示采集状态。
- 输出 `posts.json` 作为主页作品汇总。
- 自动识别并显示“当前采集作者”。
- 采集结果按主页作者建立独立子目录。
- 多个主页依次处理，每个主页内部继续按照设置的线程数并发采集作品。
- 某个主页读取失败时会记录状态并继续处理下一个主页，不会中断整批任务。

两个页签分别维护输入、状态表、停止控制、保存目录和日志，不会互相覆盖运行状态。

### 保存目录

采集结果会保存在选择的目录中。建议每次任务使用单独目录，便于管理。

### 高赞评论

可选择保留 `5–10` 条评论。软件会抓取多页评论后统一筛选，并不是简单保留最先出现的评论。

评论排序规则：

1. 点赞数高的优先。
2. 点赞数相同时，清洗后字数多的优先。
3. 点赞数和字数都相同时，回复数多的优先。

### 并发线程

可设置 `1–5` 个并发线程，默认值为 `3`：

- `1`：顺序采集，速度较慢但最稳。
- `2–3`：推荐设置，速度和稳定性较均衡。
- `4–5`：适合网络及代理质量较好的环境，但更容易触发网站限流。

同一出口 IP 下不建议超过 5 线程。每篇内容还会请求评论和图片，因此实际网络请求数会高于线程数。

### 违禁词过滤

界面提供“违禁词”输入框，默认内容为：

```text
政治|中央|证券|央行
```

- 多个词使用半角 `|` 或全角 `｜` 分隔。
- 软件获取正文后会检查文章标题和正文。
- 命中任意违禁词时，状态显示具体命中内容，例如“含违禁词：政治”。
- 命中后不会继续抓取评论或下载图片，也不会生成该文章的 TXT。
- 命中的具体词会写入 `采集日志.txt`。
- 输入框留空可关闭违禁词过滤。
- 修改违禁词后会自动保存，无需点击额外按钮。
- 下次打开软件时会自动恢复上一次填写的内容。
- 配置优先保存在 EXE 同目录的 `config.json`；如果目录不可写，则保存到 `%APPDATA%\ToutiaoCrawler\config.json`。

配置文件示例：

```json
{
  "config_version": 1,
  "blocked_words": "政治|中央|证券|央行|新增词"
}
```

### SOCKS5 代理

代理输入框留空时使用本机网络。支持以下格式：

```text
127.0.0.1:1080
host:port
host:port:user:password
socks5://user:password@host:port
socks5h://user:password@host:port
```

建议使用 `socks5h`，使域名解析也通过代理完成。

## 四、输出结构

### 微头条链接采集

```text
选择的保存目录\
├─ 内容\
│  ├─ 作品ID_内容开头.txt
│  └─ ...
├─ 图片\
│  ├─ 作品ID_内容开头\
│  │  ├─ 01.jpeg
│  │  └─ 02.jpeg
│  └─ ...
└─ 采集日志.txt
```

- TXT 中只保存正文和评论，不保存标题、摘要、作者、发布时间、原文链接和文章点赞数。
- 评论直接追加在正文后面。
- 个人主页正文结尾的 `【lm】`、`【gmj】` 等已知来源标识会自动清除。
- 评论点赞数仅用于排序，TXT 中不会写入“（赞 N）”。
- TXT 文件名去掉 `.txt` 后，与对应图片文件夹名完全相同。
- TXT 使用 `UTF-8 BOM` 编码，可直接用 Windows 记事本打开。

### 个人主页采集

主页 TXT 示例：

```text
https://www.toutiao.com/c/user/token/主页Token1/?tab=wtt
https://www.toutiao.com/c/user/token/主页Token2/?tab=wtt
```

点击个人主页页签中的“导入主页 TXT”即可载入。仍可在主页链接输入框中手动填写一个主页。

```text
个人主页保存目录\
├─ 主页作者A\
│  ├─ 内容\
│  ├─ 图片\
│  ├─ posts.json
│  └─ 个人主页采集日志.txt
└─ 主页作者B\
   ├─ 内容\
   │  ├─ 作品ID_内容开头.txt
   │  └─ ...
   ├─ 图片\
   │  ├─ 作品ID_内容开头\
   │  │  ├─ 01.jpeg
   │  │  └─ ...
   │  └─ ...
   ├─ posts.json
   └─ 个人主页采集日志.txt
```

- `posts.json` 汇总本次成功采集的主页作品。
- 个人主页和微头条链接采集可以选择不同保存目录。
- Cookie 文件中只应放完整 Cookie 字符串，请勿分享或上传该文件。

## 五、评论清洗规则

为了方便后续程序处理，保存评论前会进行清洗：

- 删除 `[飞吻]`、`[捂脸]`、`[鼓掌]`、`[招财进宝]` 等方括号表情标记。
- 删除 👏、👍、😂、❤️ 等 Unicode 表情和特殊图形符号。
- 表情前后的正常文字会保留。
- 清洗后只剩表情、空白或标点的评论会被丢弃。
- 包含 `@豆包` 的自动问答类评论整条排除。

示例：

```text
祝你们幸福快乐，[招财进宝][招财进宝]
```

保存为：

```text
祝你们幸福快乐，
```

## 六、状态说明

- `等待采集`：尚未开始。
- `采集正文（N秒）`：正在请求和解析正文。
- `采集评论（N秒）`：正在抓取并筛选评论。
- `下载图片（N秒）`：正在保存图片。
- `完成`：该链接已成功保存。
- `含违禁词`：标题或正文命中违禁词，已跳过评论和图片采集。
- 状态会附带命中的具体词，例如 `含违禁词：政治、中央`。
- `评论数不足：3＜10`：作品总评论数低于设置值，不抓评论和图片。
- `超出时间范围：日期时间`：作品发布时间不在设置范围内。
- `发布时间未知`：启用时间限制后无法取得发布时间，为避免误采而跳过。
- `失败：原因`：该链接采集失败，软件会继续处理下一条。
- `已停止`：点击停止后未继续处理的链接。

## 七、网络与故障排查

### 一直停留在“采集正文”

新版具有连接超时、读取超时、硬超时和自动重试，不会无限等待。常见原因包括：

- 对方网络无法访问今日头条。
- DNS 解析异常。
- IP 被临时限制或触发网站风控。
- SOCKS5 代理不可用、账号密码错误或延迟过高。
- 安全软件拦截 EXE 联网。

失败后查看保存目录中的 `采集日志.txt`。日志会记录失败链接、时间和错误原因。

### EXE 无法启动

- 首次启动等待几秒。
- 将 EXE 放到普通可写目录后再运行。
- 检查 Windows Defender 或其他安全软件是否拦截。
- 不要直接在压缩包内运行，先完整解压。

## 八、源码运行

仅开发或调试时需要：

```powershell
python -m pip install -r requirements.txt
python .\toutiao_ui.py
```

命令行采集：

```powershell
python .\toutiao_crawler.py -n 10 --comment-pages 3 -o output
```

使用代理：

```powershell
python .\toutiao_crawler.py --proxy 127.0.0.1:1080
```

## 九、使用提醒

- 请控制采集频率，避免短时间发起大量请求。
- 网站接口或页面结构变化后，软件可能需要同步更新。
- 请仅在符合网站规则及适用法律法规的范围内使用。

## 十、发布新版本

项目更新源：`HunterWangwei/ToutiaoCrawler` 的 GitHub Releases。

发布时同步修改 `version.py` 中的版本号，然后创建版本标签：

```powershell
git tag v1.6.0
git push origin v1.6.0
```

GitHub Actions 会自动构建 `ToutiaoCrawler.exe`、生成 SHA256 校验文件并发布到 Releases。
